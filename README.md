# 🏪 Hostel Store

A simple web-based **Hostel Store Management System** for students and administrators. Students can browse products, add items to their cart, place orders, and view their purchase history. Administrators can manage products, stock, orders, payments, and sales reports.

## ✨ Features

### 👨‍🎓 Student Features

- 🔐 Student Login & Sign Up
- 🛍️ Student Store
  - Browse available products
  - Search products
  - Filter products by category
  - View product price and available stock
  - Increase or decrease product quantity
  - Add products to cart
- 🛒 Shopping Cart
  - View cart item count
  - Manage product quantities
- 📦 My Orders
  - View order history
  - Search orders or products
  - Filter orders by status
  - View order details and total amount
  - Download purchase history as PDF
  - Download individual receipts
  - Print receipts
- 🏷️ Order Status
  - Accepted
  - Collected
  - Rejected

### 👨‍💼 Admin Features

- 🔐 Admin Login
- 📦 Store Management
  - View total products
  - View available products
  - View sold-out products
  - Add new products
  - Edit product stock
  - Save product changes
  - Delete products
  - Search products
  - Filter products by category
  - Low-stock warning
- 🛒 Order Management
  - View new orders
  - Accept orders
  - Reject orders
  - View collected orders
  - Mark orders as collected after payment
  - Search by student email or Order ID
  - Filter orders by status
- 📊 Order Statistics
  - New Orders
  - Accepted Orders
  - Collected Orders
  - Rejected Orders
  - Accepted Items
  - Collected Items
  - Finished Items
  - Total Orders
- 💰 Money Tracking
  - Total Sales
  - Amount to Collect
- 📄 Sales & Collection Reports
  - Day-wise PDF report
  - Week-wise PDF report
  - Month-wise PDF report
  - Year-wise PDF report
  - Full Report PDF
  - Collected orders summary
  - Products handed over
  - Money received
  - Product-wise totals
